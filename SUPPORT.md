# Support

- For a translation, lexical, or commentary correction, open a repository
  issue using the correction form.
- For a clear, narrow correction, follow `CONTRIBUTING.md` and open a pull
  request.
- For application help, display defects, copyright questions, or private
  matters, visit [Selah support](https://selahproject.com/support).
- For security, privacy, account, or conduct reports, do not open a public
  issue. Follow [SECURITY.md](SECURITY.md) or contact
  `support@selahproject.com`.

Please do not send passwords, sign-in links, access tokens, or unrelated
personal information.
